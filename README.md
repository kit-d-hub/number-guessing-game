# Number Guessing Game

A simple console-based game written in **Python** where the player tries to guess a secret number generated by the computer within a limited number of attempts.

## 🎮 Gameplay
1. Upon launch, the game prompts the user to either start a new game (input `1`) or exit (input `0`).
2. The computer selects a random integer between **1 and 100**.
3. The player is given **10 attempts** to guess the number correctly.
4. After each guess, the game provides a hint stating whether the secret number is *higher* or *lower* than the player's guess.
5. Features a **custom reward system** with special congratulatory messages if you guess the number on your 1st or 3rd attempt.

## 🛠 Features & Implementation Details
* **Input Validation:** If the user enters letters, an empty string, or a number outside the 1-100 range, the game displays an error message. The current attempt is **not penalized** (the counter does not decrease).
* **Game Loop:** Once a game ends (win or lose), the program resets and prompts the user to start a new round instead of closing unexpectedly.
* **Modern Python:** Branching and validation logic utilizes the `match/case` structural pattern matching (introduced in Python 3.10+).

## 🚀 How to Run

### Prerequisites
* **Python 3.10** or higher installed on your system.

### Instructions
1. Clone this repository or download the source files.
2. Open your terminal (command prompt) in the project directory.
3. Run the script by replacing `<filename>.py` with your actual file name (e.g., `main.py` or `game.py`):
   ```bash
   python <filename>.py
   ```
